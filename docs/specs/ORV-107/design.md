# CanvasChat sidebar: visual refresh

The owner said the chat looks dated and its spacing is broken (comment 10138), sent references (10140), chose the Framekit-style language for the board and the chat (10142, with the dark reference in ORV-110 10143) and decided R2 to R6 (10144). This version turns those decisions into a target: the chat is a floating card on the board, quiet at the top, one rounded composer at the foot with the honesty line under it, and starter prompts when nothing has been asked yet. Each change lists its target px, the tokens it reads and the play assertion that proves it, in light and dark.

No semantic token changes. No `CanvasChatProps` change. Four new locale keys, all for the starters (spec v1.3 row 34). Behaviour, focus order, live regions and every honesty rule of ORV-105 design.md stay, except the deltas in §9. Board nodes and the reply note are not restyled here (ORV-110).

```
│           └─ div.ds-chat__reply                 plain text, start edge, full width
│               ├─ p.ds-chat__text
│               └─ div.ds-chat__meta              32 px lines: progress | basis, stopped, Jump (icon + text), unlinked
├─ form.ds-chat__composer                         no hairline
│   ├─ div.ds-chat__picker                        over the transcript, the box's width, 8 px above it
│   ├─ div.ds-chat__box                           one rounded container, one edge, one focus ring
│   │   ├─ ul.ds-chat__chips                      first row; absent when empty
│   │   ├─ Textarea (borderless, rows 1)
│   │   └─ div.ds-chat__actions                   Mention (icon) .... counter, Send or Stop (icon, round)
│   └─ p.ds-chat__notice (id)                     the honesty line, centred, always rendered
├─ Button close (DOM last, drawn in the header row)
└─ span.sr-only role=status
```

The notice moves from above the transcript to under the box, so the textarea gets `aria-describedby` that includes the notice's id next to the counter's: a screen reader hears the honesty line every time it enters the field, before anything is sent. Tab order: starters (when shown), transcript, Send again, textarea, Mention, Send or Stop, close. The listbox wiring, `aria-activedescendant` and both live regions are unchanged.

## 7. Light and dark

Same geometry in both modes; only these colours differ, each from an existing semantic token.

| Part                 | Light                                                   | Dark                                                                         |
| -------------------- | ------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Board under the chat | `surface.board` gray.100                                | `surface.board` gray.950                                                     |
| Panel                | `surface.card` white, `shadow.overlay`, no visible edge | `surface.card` gray.800, `shadow.overlay-dark`, 1 px `border.card` gray.700  |
| Header icon, title   | `text.secondary` icon, `text.primary` title             | Same tokens: gray.400 icon, gray.100 title                                   |
| Question bubble      | `surface.sunken` gray.100 on white                      | `surface.sunken` gray.950 on gray.800: a darker inset, as the dark reference |
| Reply, meta, notice  | `text.primary`, `text.secondary`                        | Same tokens                                                                  |
| Box                  | `surface.card` ground, gray.500 edge (3.72 on white)    | gray.800 ground, gray.500 edge (4.48 on gray.800)                            |

| Starters             | `button.secondary.*`                                    | Same tokens                                                                  |

The box keeps a 3:1 edge on purpose: a lighter `border.subtle` edge would look closer to the references but fails the UI contrast floor, and the field must be findable without the placeholder.
