## Evidence

Read on 2026-11-06 through a fetch tool that returns a summary with quotes of at most 125 characters.

> Labels or instructions are provided when content requires user input.

> Instructions or labels may also specify data formats for data entry fields.

> especially if they are out of the customary formats or if there are specific rules for correct input

> A field for entering a date has text instructions to indicate the correct format for the date.

The page notes that "requires" stands for "accepts", "expects" or "allows", so the criterion covers optional fields too. No file example appears in what the fetch returned.

## Why it matters for ORIVILO

A size and type line shown before a person chooses a file fits "specific rules for correct input" (own reading). It is the visible half of the "limits shown" check on row 24 of the ORV-64 build order.
