### What the standards say

- Keys: Enter or Space expand a collapsed panel and collapse an expanded one if the implementation supports it; Tab and Shift + Tab follow the page Tab sequence (K-0347). The pattern and its example list no arrow, Home or End (K-0347, K-0350).
- Heading: the button sits alone in a heading with an `aria-level` that suits the page; a native heading may be used (K-0348). The example uses `h3` (K-0350).
- `aria-expanded`: true while the panel is visible, false while not (K-0348); the 1.2 value set is true, false, undefined (K-0351).
- `aria-controls`: set to the panel's ID in the Accordion pattern (K-0348), optional in the Disclosure pattern (K-0123).
- `aria-disabled`: true on a visible panel's button when the accordion does not permit collapse (K-0349). The example has no such line (K-0350).
- `region`: optional; avoid where it creates landmark proliferation, for example more than approximately 6 panels open at once (K-0349).
- Separator: static when not focusable, related to `hr`; focusable needs `aria-valuenow` (K-0357). Implicit `aria-orientation` is horizontal; children are presentational (K-0358).
- Metric and Filter bar: this task's question set no standard for either, and none was read.

- `region` is set on the Content in Radix's source (K-0345), where the APG makes it optional (K-0349). A caller's `role` comes later in the spread, by our reading of K-0345.
- `decorative` defaults to true in shadcn/ui's Separator and has no default in Radix's (K-0355, K-0356). Untitled's Content divider states it is not a separator (K-0353); `SectionDivider` uses `hr` (K-0354).
