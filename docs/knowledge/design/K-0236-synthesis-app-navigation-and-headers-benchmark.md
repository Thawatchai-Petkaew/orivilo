### Answers across the libraries

- Current page: `aria-current="page"` is set by Untitled's `NavItemBase` (K-0205) and Breadcrumbs (K-0212), Radix's Link (K-0221) and shadcn's BreadcrumbPage (K-0222). It is not set by Untitled's `NavButton`, which draws the rail and the header rows in the buttons form (K-0206, K-0209), or by shadcn's sidebar file (K-0215). WAI-ARIA 1.2 says one element in a set (K-0226); WCAG lists it for SC 2.4.8, level AAA (K-0227).
- Landmarks: Radix's root has a `nav` with a default name (K-0221). Untitled's header has `nav` with no name (K-0209). The sidebar sources read have no `nav` (K-0205, K-0216). Both Breadcrumbs have a named `nav` (K-0212, K-0222).
- Small screens: both sidebars become a modal drawer (K-0207, K-0217), and Untitled's header does too (K-0209). In what was read, shadcn's Navigation Menu has no such statement or code (K-0219). SC 1.4.10 has a hamburger example at 320 CSS pixels (K-0233).
- Nested items: a disclosure in both sidebars, native `details` in Untitled (K-0205) and Radix Collapsible in shadcn's block (K-0218). Radix's menu uses a button with `aria-expanded` (K-0221), and the APG's disclosure navigation has the same shape (K-0229). The sidebar group labels read are not headings (K-0205, K-0216).
- Collapse: a desktop control a person presses is stated by shadcn (K-0213, K-0214); Untitled's page states none (K-0204). The hover panel is read from the Slim and Dual-tier files (K-0206).
- Skip links: the fetched text of the library pages named none (K-0232).
- Heading order: WHATWG states a "must" (K-0231); the WCAG pages read state it as guidance, and SC 2.4.10 is AAA (K-0230). The APG pages read do not state it (K-0230).
