### What the primitive and the pattern give

- Roles: Radix renders role radiogroup on a `div`, role radio on `button` items (K-0151), role switch on a `button` (K-0152). APG asks for the same roles (K-0153, K-0154).
- Keyboard, radio: APG has Tab in and out, Space, arrows that move, check and wrap (K-0153). Radix has `loop` default true and clicks on arrow focus, on the reading in K-0151; its docs rows for ArrowUp and ArrowLeft omit the check (K-0150).
- Keyboard, switch: APG has Space, and Enter as optional (K-0154). Radix docs list both (K-0152).
- Labelling: APG asks for a label on the group and on each radio (K-0153) and gives three ways to name a switch (K-0154). Radix's two docs pages say nothing on it (K-0150, K-0152).

### Statements scoped to the pages read

- Invalid: Untitled's three pages name no invalid state (K-0144, K-0145, K-0146). shadcn documents one for both controls (K-0147, K-0148). The Radix builds set no `aria-invalid` and spread extra props (K-0151, K-0152). The APG pages do not mention it (K-0153, K-0154). ARIA 1.2 lists it on radiogroup and switch and marks it deprecated on radio (K-0155).
- Disabled look: K-0144, K-0146, K-0147 and K-0148 use 50% opacity; K-0145 states no look.
- Saving: no page or file read for K-0144 to K-0154 shows a pending or saving state on a switch. "Loading" is absent from the toggles page (K-0146); the section lists in K-0148 hold none; Radix's state is checked or unchecked (K-0152).
- Field: of the two controls, the Radix switch can take `Field`'s `label htmlFor` and the radio group root cannot (K-0151, K-0152, K-0156).

### Open points

- Checked fill. `audit.md` B.4 says checked uses selection tokens, `component.json` line 895 has `checkbox.bg-checked` reading `action.primary`, and `DESIGN.md` section 8 gives Selected to `surface.selected`. Which token a checked radio and an on switch read is the designer's call.
- Own label or Field. `checkbox.yaml` line 22 keeps Checkbox out of `Field`, and D.3 row 18 of `audit.md` asks for Field wiring on both new controls.
- Whether a `fieldset` and `legend` around a role radiogroup `div` satisfies the name that role requires was not read in any source.

### Not read

- The Untitled UI API tables on all three pages, and the Radio groups component files (K-0144, K-0145, K-0146).
- React Aria's RadioGroup and Switch docs, which Untitled builds on.
- Base UI's API pages and shadcn's React Aria variants, beyond the Base UI sentences in K-0147.
- shadcn styles other than `style-nova.css` and `new-york-v4` (K-0147, K-0148).
- The APG example pages (K-0153, K-0154), and the `aria-required` definition block in ARIA 1.2 (K-0155).
