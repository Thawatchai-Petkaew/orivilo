### Statements scoped to the pages read

- None of the publisher pages read (K-0120, K-0121) sets a reduced-motion rule; shadcn adds no animation at all and Radix's example has none in the docs page and its source (K-0121).
- Radix drops `aria-controls` while closed (K-0122), and the shadcn Radix file inherits that, since it only adds `data-slot` (K-0120); the APG makes `aria-controls` optional (K-0123); our TaskBar and Resizable keep it set while closed, pointing at a hidden element (TaskBar.tsx, Resizable.tsx).
- The 2.3.3 and 2.2.2 readings for a collapsible are ours; neither Understanding page names collapsibles (K-0124, K-0125).

### Open points

- Whether the shared Collapsible animates height (a 2.3.3 motion case) or fades opacity like TaskBar (not motion by the definition) is for the designer (K-0124).
- Whether TaskBar and Resizable move onto the new component is outside this entry; the Ours row only records what they do today.
- Untitled's FAQ accordion code and Base UI's Collapsible API were not read (K-0119, K-0120).
