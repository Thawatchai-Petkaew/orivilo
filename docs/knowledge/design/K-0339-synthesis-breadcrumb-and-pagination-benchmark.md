### What the standards say

- `aria-current` on a trail: `page` on a link to the current page, optional on a non-link (K-0333). The APG example sets it on the last link (K-0334). G65 tests both forms (K-0337).
- `aria-current` in general: seven values, `page` for a page in a set, one per set, not a substitute for `aria-selected` (K-0336). ARIA26 is sufficient for 1.3.1 and 2.4.8 (K-0338).
- Landmark: the trail sits in a navigation landmark, labelled by `aria-label` or `aria-labelledby` (K-0333), using `nav` (K-0335, K-0338).
- Names: several navigation landmarks take a unique label each, with no role word in it (K-0335). ARIA11 and H97 tell them apart by label (K-0338). The APG example's label is "Breadcrumb" (K-0334).
- Level: a breadcrumb is one sufficient route to SC 2.4.8 Location, Level AAA (K-0337).
- Pagination: no APG pattern (K-0335). A word search of ARIA11, H97 and the Location page found no hit for it, and ARIA26 does not mention it (K-0337, K-0338).
- Collapse: word searches of the APG pattern, G65 and the Location page found nothing on collapsing or shortening a trail (K-0333, K-0337).

### Statements scoped to the pages read

- Of the two libraries read, only Untitled UI collapses a trail or computes a page range on its own (K-0321, K-0327); shadcn/ui leaves both to the caller (K-0325, K-0331).
- Three forms of the current crumb were read: a disabled link (K-0322), a `span` with `role="link"` (K-0324), and a real link (K-0334). G65 accepts a non-link or a link with `aria-current` (K-0337).
- Both libraries set `aria-current="page"` on the current page in pagination and hide the ellipsis there (K-0328, K-0332).
- Every name read in both libraries is English in the file or page (K-0322, K-0324, K-0328, K-0332); shadcn's `text` prop in `bases/radix` covers the visible Previous and Next words (K-0330).
- Keyboard: the APG says none is needed for a trail (K-0333, K-0334). The Untitled pages describe none (K-0320, K-0326). The sources read here do not set out keyboard behaviour for an ellipsis control or a menu inside a trail.

### Open points

- The current crumb: a link with `aria-current="page"` or a non-link. The audit's D.3 wording ("Current page marked `aria-current`") fits both, but the APG makes it optional on a non-link (K-0333).
- Untitled's disabled, unfocusable last link (K-0322) against the APG example's real link (K-0334): the Untitled page gives no reason, so this is a question for the designer, not a fault found.
- The current page's look: `--cmp-nav-item-*-active` or `surface.selected`. DESIGN.md section 7 lists `selected` for options, rows and tabs, and ARIA says `aria-current` is not a substitute for `aria-selected` (K-0336), so whether "current" is a selected state is for the designer.
- Page items as links or buttons depends on whether decision-log pages have URLs, which no source read settles.
- A collapse by count or by composition, and what the ellipsis opens (K-0321, K-0325).
- Chevron and ellipsis glyphs are missing from `icons.tsx`; DESIGN.md section 6 sets the order for adding them.
